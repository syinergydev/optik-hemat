OPTIK HEMAT SIDOARJO — Website statis (multi-halaman)

DEPLOY
- Upload seluruh isi folder ini ke Netlify (drag & drop) atau GitHub Pages.
- Setelah domain final ada, ganti GANTI-DOMAIN-ANDA di robots.txt dan sitemap.xml.

DATA
- Info bisnis, paket & harga, layanan, dan ulasan ada di assets/js/data.js.
- Foto produk: assets/products/<slug>/NN.webp. Banner hero: assets/img/banner.webp.

CATATAN SEBELUM PUBLISH
- Foto suasana toko belum ada di materi (ZIP tambahan hanya berisi screenshot, promosi, dan dokumen).
  Ganti foto "Tentang Kami" dengan foto toko asli saat tersedia.
- Dokumen registrasi, sertifikat, dan screenshot ulasan dengan data pribadi TIDAK dipublikasikan.
- Ulasan ditampilkan tanpa nama pelanggan. Ulasan yang berisi informasi kesehatan pribadi dihilangkan.
- Harga mengikuti listing marketplace klien. Pastikan masih berlaku sebelum publish.
- Pemeriksaan mata tercantum pada listing klien; pastikan layanan ini memang tersedia.
- Logo diambil dari banner hero (versi putih dan hijau). Jika ada file logo resmi, ganti di assets/img/.
- Ikon WhatsApp, Instagram, email, dan Google Maps dimuat dari CDN jsdelivr (butuh internet).
- Facebook dan TikTok tidak disertakan karena akun tersebut tidak diberikan.
- Animasi GSAP dimuat dari CDN jsdelivr.
